# ==========================================================================
# ChatGPT locators
# --------------------------------------------------------------------------
# Each line is a real Playwright locator expression, identical to what the
# Python scripts used before this file existed:
#
#     key = <playwright expression> :: <vision description>
#
# - The expression is evaluated with `page` (the current Playwright Page) and
#   `re` in scope. Edit it exactly as you would edit the Python call.
# - Everything after ` ::` is optional. It is the natural-language description
#   handed to Gemini Vision when the expression matches nothing, so keep it
#   specific about position, label, and icon.
# - `{placeholder}` values are filled by the calling script.
# - Use `||`-free syntax: a key holds exactly ONE expression. For alternative
#   selectors, chain them with Playwright's own `.or_(...)`.
#
# Self-healing fallbacks: a key may also declare EXTRA lines directly beneath its
# primary line. The first line for a key is the primary; each following line with
# the same key is an ordered fallback tried only when the primary (and earlier
# fallbacks) fail. Fallback lines do not need a `::` description. When a locator
# breaks and Gemini suggests a fix, `locators/changed_locators.json` records it and
# (when `locator_healing.auto_correct_locator` is true) the suggestion is appended
# here as a new fallback line under the same key.
#
# Keep this file free of Python-side locators: scripts must only reference keys.
# ==========================================================================
